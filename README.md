[Simple-Machine-learning]

a simple C-based code that uses the foundings of machine learning forward propagation and backpropagation 
to predict the probability of rain based on avg temperature, wind speed and pressure adjusted to have 
a good succes rating lean to the learning data. The code its very light totally scripted on C language
and mainly designed to implement it on IoT devices and small microcontrollers with just basic c lib and the math.h library
